Live inference for the archived Stage 2 checkpoint — upload or record a clip and hear what the model generates.

This checkpoint predates the duplex-fusion fix: during training it could lean on the real ground-truth audio instead of learning independent generation, so self-feedback generation here may sound rough. Treat this as a snapshot of an early run, not the model's ceiling.

1. Mode

The model generates its response window-by-window, feeding its own output back in as it goes — this is the only mode that reflects how the model would actually be used.

Both clips must be the SAME time window of a real two-channel recording — e.g. a user/agent pair from otoSpeech. This mode feeds the model the real answer (shifted one frame), so it only works with real paired audio, not a clip you record yourself.

Both files must be shared as "Anyone with the link" in Google Drive first (right-click → Share). Paste the share links below — the server downloads the full session files and trims them to the window you specify, so you don't have to cut clips yourself.
